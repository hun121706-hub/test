---

## 무엇을 만드나

국유재산 업무 전반(사용허가·기부채납·변상금·용도폐지·회계 처리·대부·처분·취득)에 대한 법령 검토 요청을 받아, 사안을 분류하고 근거 조문·유사 선례·확인 필요 사항을 정리한 검토서 초안을 만든다.

**참고자료 보유 수준에 따라 응답 깊이를 달리하고, 근거가 확보되지 않은 영역은 반드시 그 사실을 밝힌다.**

---

## 왜 만드나

- 국유재산 업무는 사안마다 근거 조문이 법·시행령·시행규칙에 흩어져 있어, 매번 법령과 과거 사례를 처음부터 다시 찾아야 한다.
- 판단 근거가 문서에 남지 않는 경우가 많아 담당자가 바뀌면 기준이 소실된다.
- 영역마다 확보된 근거의 두께가 다른데, **근거를 확인해서 답한 것과 근거 없이 답한 것이 결과물에서 구분되지 않는다.**

## 어떻게 만드나 (6단계)

| 단계 | 하는 일 | 수행 | 비고 |
|---|---|---|---|
| 1 | **사안 분류** — 문의 내용에서 **업무 영역**(사용허가·기부채납·변상금·용도폐지·회계 처리·대부·처분·취득)과 **쟁점**, 그리고 대상 재산·신청인·용도·기간·면적·**특수관계(협약 등)** 를 추출 | AI → **사람 확인 ★** | 누락 항목 질문 |
| 2 | **참고자료 보유 확인** — 해당 영역의 법령 발췌·사례가 참고자료에 있는지 확인하고 **응답 수준을 결정** | AI | 아래 판정 기준 |
| 3 | **요건 대조** — 해당 영역·쟁점의 근거 조문을 **부록 1**에서 찾아 요건을 본 건 사실관계와 하나씩 대조한다. 요건이 각 호로 열거된 사안은 **제1호부터 순서대로** 대조하고 포괄 사유는 마지막에 본다 | AI | 계약방법 사안은 부록 2 |
| 4 | **유사 선례 검색** — `사례요약.md`에서 **같은 영역·같은 근거 조문을 적용한 건**을 찾는다 | AI | 3과 병렬 |
| 5 | **리스크·확인사항 도출** — `법령제외규칙.md` 대조, 판단에 필요한데 확보되지 않은 사실을 식별 | AI | |
| 6 | **결과물 생성** — 검토서(hwpx) + 근거자료(md) | AI → **사람 최종 확인 ★** | |

**2단계 응답 수준 판정**

| 보유 상태 | 응답 수준 |
|---|---|
| 법령 발췌 + 사례 **모두 있음** | **정식 검토서** |
| **일부만 있음** | 검토하되 **미확보 근거를 명시** |
| **없음** | **범위 밖임을 밝히고 일반 안내만** |

**사람이 개입하는 지점은 2곳이다.** 1단계 직후(사안 정보 확정)와 6단계 직후(최종 확인).

## 무엇을 만드나 (결과물)

### ① 국유재산 법령해석 검토서

- **형식**: hwpx, **위치**: `결과물/`
- **구성**
  - 사안 분류 (업무 영역 · 쟁점)
  - **응답 수준** (정식 검토 / 일부 근거 미확보 / 범위 밖)
  - 검토 결론
  - 근거 조문 및 요건 대응
  - 유사 선례
  - 후속 절차
  - 확인 필요 사항
- 제목에 **"1차 검토 초안"**, 하단에 **"최종 판단은 담당자가 수행"** 고정

**검토 결론의 형태** — 사안 유형에 따라 다르다. 어느 쪽이든 **하나로 확정**해서 적는다.

| 사안 유형 | 결론 형태 |
|---|---|
| 계약방법 판단 | 수의계약 / 제한·지명경쟁 / 일반경쟁 / 추가확인 |
| 요건 충족 여부 판단 (감면·전대 승인·기간 연장 등) | 가능 / 불가 / 추가확인 |
| 금액 산정 | 산출액 + 적용 요율·근거 조문 |
| 절차 안내 | 단계별 절차 + 필요 서식 |
| 범위 밖 | 범위 밖 고지 + 일반 안내 |

**양식 골조** — `양식_사용허가_검토보고서.hwpx`에서 확인한 구조다. 서식·글머리만 따르고 본문 내용은 쓰지 않는다.

| 순서 | 양식 원래 항목 | 이 에이전트에서 |
|---|---|---|
| 제목 | 「○○ 국유재산 사용허가 검토」 | 「○○ 국유재산 ○○ 검토」 (영역명 반영) |
| 머리 | `<'YY. M. D.(요일), 부서>` | 그대로 |
| 1 | `□ 검토배경` | 그대로 (사안 분류·응답 수준 포함) |
| 2 | `□ 허가기간 및 사용료율 검토` | **`□ 검토 결과`** |
| 3 | `□ 참고사항` | 그대로 |
| 4 | `□ 주요대학 운영 사례` | **`□ 유사 선례`** |
| 5 | `《관련 법령》` 인용 박스 | 그대로 |

`□` 대절 → `◦` 중절 → `-` 소절 글머리와, 인용 자료를 `《 》` 박스로 감싸는 방식을 따른다.

**작성 규칙**

- 「참고사항」에는 본 건 결론에 직접 관계되는 사항만 적는다.
  결론과 무관한 용어 설명·일반 상식은 넣지 않는다.

### ② 검토 근거자료

- **형식**: md
- **구성**
  - 적용 법령표 (조문 · 요지 · 검토서 반영 위치 · 출처 파일)
  - 유사 선례표
  - 확인 필요 사항
  - 근거 없어 판단 보류한 항목

## 다 됐다고 볼 기준

- [ ] **업무 영역과 쟁점이 분류**되어 있고, 2단계 **응답 수준**(정식 검토 / 일부 근거 미확보 / 범위 밖)이 명시되어 있다
- [ ] 검토 결론이 위 「검토 결론의 형태」 중 하나로 **확정**되어 있다
- [ ] 인용한 **조문·호 번호를 법령 md에서 확인**해 `[파일명 · 조번호]`로 표기했다
- [ ] 요건과 본 건 사실관계의 대응이 **조문별로** 적혀 있다
- [ ] 확인 필요 사항이 별도로 명시되어 있다
- [ ] 참고자료에 근거가 없는 부분은 **그 사실이 결과물에 드러나** 있다
- [ ] 추측으로 채운 문장이 없다

**수준별로 결과물에 반드시 들어가야 하는 것**

| 응답 수준 | 결과물 처리 |
|---|---|
| 정식 검토 | 조문·선례를 모두 인용한 검토서 |
| 검토 가능 | 검토서 + **미확보 근거를 「확인 필요 사항」에 특정해서 기재** (예: "법 제13조 원문 미확보") |
| 범위 밖 | 검토서를 만들지 않고 **범위 밖임을 밝히고 일반 안내만**. 조문을 인용하지 않는다 |

> 이 표는 2026-08-19에 참고자료 파일을 기계 대조해 초안의 4행짜리 목록을 대체한 것이다. 초안은 변상금을 "법 제72조·영 제71조", 기부채납을 "조문 미발췌", 대부·처분·용도폐지를 "자료 없음"으로 묶어 적었으나, 실제로는 변상금 근거가 12개 조문으로 완비되어 있고 용도폐지·회계 처리에도 조문이 있으며 기부채납은 법 제13조만 빠져 있었다.

## 절대 규칙

1. **조문 호 번호는 반드시 법령 md에서 확인한다.** 사례 문서의 호 번호를 그대로 쓰지 않는다.
2. **`사례요약.md`의 "근거 미기재" 항목은 선례로 인용하지 않는다.**
3. **참고자료에 없는 근거는 인용하지 않고 "확인 필요"에 기재한다.**
4. **교내 기준은 법령 근거로 인용하지 않는다.**

## 부록 2. 시행령 제27조 각 호 (계약방법 사안 대조용)

절대 규칙 1에 따라 실제 인용은 매번 `법령_국유재산법시행령_사용허가.md`에서 확인한다. 2026-08-19 확인 상태이며 대조용 요약이다.

| 호 | 요건 요약 |
|---|---|

**제9호 사용 시 주의** — 교내 사례 3건이 모두 제9호를 근거로 삼았다. 제9호를 적용하는 경우 "왜 경쟁입찰에 부치기 곤란한지"를 본 건 사실관계로 적어야 한다.

※ 제3항 제1호~제8호 및 제2항 적용 선례는 참고자료에 없다. 해당 호로 판정하는 경우 **"교내 선례 없음"** 을 결과물에 명시한다.

## 운영 유의점

**① 부록 1은 발췌 파일에서 만든 색인이다.** 조문 내용을 요약한 것이 아니라 "어느 파일 어느 조문을 봐야 하는지"만 적었다. 발췌 파일에 조문이 추가되면 부록 1과 「영역별 자료 보유 수준」 표를 함께 갱신해야 한다.

**② 3단계·4단계가 조회할 수 있는 수의계약 선례는 제9호뿐이다.** `사례요약.md`의 사용허가 사례는 사례 1·3이 제9호, 사례 2가 입찰/수의 판별 불가, 사례 4가 무상사용허가다. 제1호~제8호와 제2항 적용 건은 참고자료에 없다.

**③ 사례 1의 「근거 미기재」는 사용료율·허가기간에만 걸린다.** 수의계약 판단 자체는 2020년 법률자문이 근거로 기재되어 있으므로, 절대 규칙 2가 계약방법 판단까지 막지는 않는다.
