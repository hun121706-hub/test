# 국유재산 법령해석 검토 에이전트

국유재산 업무의 법령 검토 요청을 받아, 사안을 분류하고 **근거 조문 · 유사 선례 · 확인 필요 사항**을 정리한 검토서 초안을 만드는 Claude Code 에이전트입니다.

참고자료 보유 수준에 따라 응답 깊이를 달리하고, **근거가 확보되지 않은 영역은 반드시 그 사실을 결과물에 밝힙니다.**

---

## 이 저장소에 없는 것

아래는 `.gitignore`로 **의도적으로 제외**했습니다. 실명·지번·금액이 그대로 들어 있는 원본 행정문서와 사안별 산출물이기 때문입니다. 로컬에서는 해당 폴더에 파일을 그대로 두고 씁니다.

| 경로 | 내용 | 제외 이유 |
|---|---|---|
| `참고자료/사례/` | 교내 사례 원본 6건 (hwpx · pdf) | 익명화되지 않은 실명 행정문서 |
| `참고자료/원문/` | 법령 PDF 원본 5건 | 공개 법령이나 용량이 크고 md 발췌로 대체됨 |
| `수집자료/` | 요청 건마다 새로 받는 자료 | 사안별 작업 파일 |
| `결과물/` | 사안별 검토서 · 근거자료 | 교내 정보 포함 |

> `참고자료/사례요약.md`는 업체명·성명을 익명 부호(`A업체`, `B업체` 등)로 바꾼 요약이지만, 지번·금액·협약기간 등 교내 정보가 일부 남아 있습니다. **저장소는 private으로 유지하세요.**

## 절대 규칙

1. **조문 호 번호는 반드시 법령 md에서 확인한다.** 사례 문서의 호 번호를 그대로 쓰지 않는다.
2. `사례요약.md`의 **"근거 미기재" 항목은 선례로 인용하지 않는다.**
3. **참고자료에 없는 근거는 인용하지 않고 "확인 필요"에 기재한다.**
4. **교내 기준은 법령 근거로 인용하지 않는다.**

## 워크플로우 (6단계)

| 단계 | 하는 일 | 수행 |
|---|---|---|
| 1 | **사안 분류** — 업무 영역·쟁점, 대상 재산·신청인·용도·기간·면적·특수관계 추출 | AI → **★ 사람 확인** |
| 2 | **참고자료 보유 확인** — 응답 수준 결정 (범위 밖이면 3~6단계 중단) | AI |
| 3 | **요건 대조** — `법령검색담당` | AI |
| 4 | **유사 선례 검색** — `사례검색담당` | AI |
| 5 | **리스크·확인사항 도출** — `법령제외규칙.md` 대조 | AI |
| 6 | **결과물 생성** — 검토서(hwpx) + 근거자료(md) | AI → **★ 사람 최종 확인** |

- **3·4단계는 한 메시지에서 병렬 실행**하며, 호 번호는 `법령검색담당`의 결과를 정본으로 삼습니다.
- **사람 확인 지점은 2곳**입니다. 1단계 직후(사안 정보 확정)와 6단계 직후(최종 확인).
- 1단계 질문은 **한 번만** 합니다. "모름" 또는 "그대로 진행"이면 해당 항목을 「확인 필요 사항」으로 넘깁니다.

## 영역별 응답 수준 (2026-08-19 기준)

| 영역 | 사례 | 응답 수준 |
|---|---|---|
| 사용허가 | 3건 | **정식 검토** |
| 변상금 | 1건 | **정식 검토** (판결문 원문 미확보 — 판례는 「확인 필요」) |
| 기부채납·무상사용허가 | 1건 | **검토 가능** (법 제13조 미확보 명시) |
| 용도폐지 | 없음 | **검토 가능** (선례 없음 명시) |
| 회계 처리 | 1건 | **검토 가능** (교육부령·예산집행 기본지침 미확보) |
| 대부 / 처분 / 취득 | — | **범위 밖** (검토서를 만들지 않고 일반 안내만) |

참고자료를 추가하면 해당 영역의 수준이 올라갑니다. 이때 `CLAUDE.md`의 표와 `설계도/기획서.md` 부록 1을 함께 갱신하세요.

## 결과물

**파일명 규칙** — 두 파일은 같은 `YYYYMMDD_사안명` 을 씁니다.

- 검토서 : `결과물/YYYYMMDD_사안명_검토서(1차초안).hwpx`
- 근거자료 : `결과물/YYYYMMDD_사안명_근거자료.md`

**hwpx 생성 방법** — `참고자료/양식_사용허가_검토보고서.hwpx` 를 복사한 뒤 `Contents/section0.xml` 의 텍스트만 교체합니다. `header.xml` 등 서식 XML은 수정하지 않습니다. 문단을 복제한 경우 **모든 `<hp:linesegarray>`를 제거**해야 합니다 — 양식 문단의 줄 좌표가 남아 있으면 한글이 그 위치에 글자를 겹쳐 그립니다. 생성 후 zip 무결성을 확인합니다.

**고정 문구 2개** — 제목에 "1차 검토 초안", 하단에 "최종 판단은 담당자가 수행".

## 사용법

이 폴더를 클론한 뒤 제외된 참고자료(`참고자료/사례/`, `참고자료/원문/`)를 채워 넣고, Claude Code에서 폴더를 열어 검토 요청을 그대로 적으면 됩니다. `CLAUDE.md`가 자동으로 읽히고, 1단계 사안 분류부터 진행합니다.

설계 전체를 한눈에 보려면 `설계도/설계도.html` 을 브라우저로 엽니다 (외부 리소스 없이 A4 가로 1장).

---

**검토서는 1차 검토 초안이며, 최종 판단은 담당자가 수행합니다.**
